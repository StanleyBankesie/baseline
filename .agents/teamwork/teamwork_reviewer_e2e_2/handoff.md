In several boundary tests (`E2E-R3-T2-05`, `E2E-R4-T2-07`), tests assert hardcoded array lengths (`[...].length === 8`) or built-in JavaScript functions (`' ... '.trim()`).

The test suite does not guard against regressions in the actual codebase.
